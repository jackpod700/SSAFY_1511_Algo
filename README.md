# 💻 SSAFY_1511_Algo
SSAFY 1511기 알고리즘 스터디 저장소입니다. 정기적인 문제 풀이와 라이브 코딩을 통해 알고리즘 역량을 함께 강화합니다.

## 📅 스터디 개요
일시: 매주 월요일 정기 회의

규칙: 매주 공통 문제를 1문제 이상 풀이한 후 GitHub에 커밋

## 🎯 스터디 운영 방식
우리 스터디는 매주 1명의 ‘감독’을 선정하여 라이브 코딩을 진행합니다.

### 1. 감독의 역할
- 커밋 보류: 다른 팀원들이 풀이를 참고하지 않도록, 회의 날 전까지 본인의 코드를 커밋하지 않습니다.
- 회의 직전 커밋: 스터디 회의가 시작되기 바로 직전에 문제와 코드를 커밋하고 문제를 공유합니다.

### 2. 스터디 진행
- 라이브 코딩: 스터디 시간에는 해당 주차 감독의 문제를 대상으로 선정하여 라이브 코딩을 진행합니다.
- 힌트 및 조언: 감독은 동료의 풀이 과정을 지켜보며 옆에서 가이드, 힌트, 구현 조언을 제공합니다.

### 3. 라이브 코딩 이후
- 각 인원은 자신의 코드에 대해 왜 이렇게 접근했고 어떻게 코드를 작성했는지 발표합니다.
- 나머지 인원은 발표를 들으며 평가합니다.
